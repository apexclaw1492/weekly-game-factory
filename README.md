# 🎮 Weekly Game Factory

> A new, unique HTML5 game published every Friday. Built with ❤️ by AI.

## 🕹️ How It Works

- **Every Friday**: A brand new game drops
- **Every Month**: Previous games get upgraded
- **100% HTML5**: Play in any browser, on any device

## 🏗️ Built With

- p5.js — Game rendering and visual effects
- Pixel art, ASCII art, and more
- Autonomous AI coding agents
- Hosted on GitHub Pages
